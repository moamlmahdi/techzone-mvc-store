المتطلب الخامس (Requirement #5)

الإجابة على الأسئلة الأربعة (Who - What - Why - Where)

1. WHO?

مَن نحن ومَن يخدم المشروع؟ (Who)

نحن فريق تطوير منصة TechZone للتجارة التقنية. يخدم المشروع كلاً من مديري النظام (Admins) المسؤولين عن إدارة المخزون وقاعدة البيانات، والمستخدمين (Users) من طلاب ومبرمجين ومهتمين بالتقنية الباحثين عن مواصفات وأسعار الأجهزة الحديثة.

2. WHAT?

ماذا يقدم المشروع؟ (What)

تطبيق ويب مبني بـ ASP.NET Core MVC وقاعدة بيانات SQL مع واجهات HTML5/CSS3/JS، يقدم كتالوجاً تفاعلياً للمنتجات التقنية مع نظام صلاحيات يفصل بين القراءة فقط (User) والإدارة الكاملة للحذف والإضافة والتعديل (Admin).

3. WHY?

لماذا تم بناء هذا المشروع؟ (Why)

لتوفير مصدر موثوق ومنظم لعرض الأجهزة التقنية ومواصفاتها، وحماية قاعدة البيانات من التعديلات غير المصرح بها عبر حصر عمليات الإضافة والتعديل والحذف بمدير النظام فقط.

4. WHERE?

أين يعمل المشروع وأين يتوفر؟ (Where)

يعمل عبر متصفحات الويب على كافة الأجهزة (حواسيب، هواتف ذكية، أجهزة لوحية) ومهيأ للرفع والاستضافة على السيرفرات السحابية المجانية ليكون متاحاً في أي مكان.

المتطلب السادس (Requirement #6)

خطة المشروع (Project Plan)

الجمهور المستهدف (Target Audience) • الأهداف (Goals & Objectives) • الهيكل المستخدم (Structure Used)

1. الجمهور المستهدف (Target Audience)

الطلاب والباحثون

الراغبون في مقارنة الحواسيب المحمولة والأجهزة اللوحية المناسبة للدراسة والبرمجة ضمن ميزانيات محددة.

المبرمجون والمصممون

المهتمون بالمواصفات التقنية الدقيقة للشاشات، المعالجات، والملحقات الاحترافية.

إدارة المتجر (Admins)

المشرفون المسؤولون عن تحديث البيانات والأسعار وإضافة أو حذف المنتجات من قاعدة بيانات SQL.

2. الهدف والأهداف التفصيلية (Goals and Objectives)

الهدف العام (Main Goal)

بناء تطبيق ويب متكامل بـ ASP.NET Core MVC وقاعدة بيانات SQL يعرض المنتجات التقنية بواجهة عصرية، ويطبق نظام صلاحيات صارم بين الـ Admin والـ User.

الأهداف التفصيلية (Objectives)
  • تطبيق نمط MVC للفصل بين Models و Views و Controllers.
  • بناء قاعدة بيانات SQL لتخزين المستخدمين والمنتجات.
  • حصر عمليات الإضافة والتعديل والحذف بـ Admin فقط، والقراءة للـ User.
  • توفير صفحات Login و Register وتجهيز المشروع للاستضافة المجانية.
